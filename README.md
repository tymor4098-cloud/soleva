# Soleva

A free static starter e-commerce website for Soleva.

## Put it on GitHub Pages

1. Create a GitHub account.
2. Create a new public repository, e.g. `soleva`.
3. Upload `index.html`, `style.css`, and `script.js`.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)`, then Save.
7. GitHub will give you a free `github.io` address.

## Before launch

- Replace the sample shoe names/prices/images.
- Change the WhatsApp number in `index.html`.
- Connect a real payment provider for card checkout.
- Add your domain (`soleva.co.ke`) later if you buy it.
- Do not collect or store card numbers/CVV yourself.
